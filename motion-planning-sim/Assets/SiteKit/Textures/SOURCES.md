# Texture sources

All textures are from ambientCG, licence CC0 1.0 (public domain), 1K-JPG downloads. Only the
colour map (`color.jpg`) and the OpenGL normal map (`normal.jpg`, `NormalGL`) of each set are kept.
`lane_marking` and `walkway_marking` are plain-colour materials without textures.

running-bond grid of about 2:1 units, tinted grey and tiled at 1.8 m so the units read as
440 x 215 mm concrete blocks) replaced Bricks075A (random rubble) on 2026-10-17.

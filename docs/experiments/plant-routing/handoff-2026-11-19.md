## Implemented foundations

### Portable routing package

`ros2_ws/src/mobile_manipulator_routing/` contains a plain C++17 library, install/export configuration,
tests, configuration, pinned primitive asset and `route_check` CLI.

- Strict P5/8-bit trinary map loading, origin/row conversion, bounded dimensions and allocation checks.
- Separate known/observed occupancy values, immutable grid snapshots and Euclidean inflation.
  This is the grid foundation, not the acquisition/persistence pipeline.
- Validated primitive parsing using the actual nonuniform headings. The unchanged Nav2 diff-drive
  data has 16 headings and 112 motions; provenance, licence and SHA-256 are retained.
- Convex footprint interior/boundary checks and conservative swept-motion checks, with resumable work.
- Deterministic lattice A*, positive rotation cost, checked exact-pose connectors, cancellation and
  revision invalidation, bounded expansions/storage/collision work, and typed outcomes.
- Distinct stationary and translating results; requested final position/yaw are preserved.
- Independent synthetic qualification tool in `tools/plant/qualify_routing.py`.

The algorithm is our implementation using pinned Nav2 primitive data. Nav2-equivalence and actual-robot
route quality have not been established.

### Heading-only hierarchy support

MPC `route.*` now has an explicit stationary route. `medium_reference.*` and the medium planner support
zero translation with a final heading, while ordinary degenerate polylines remain invalid. Focused
offline F2/B5 cases exercise rotation, wrapped yaw and blocked rotation.

### Goal manager

Campaign `goal_manager.*` implements backend IDs/revisions, replacement, same-goal replanning,
deadlines, duplicate request acknowledgements, reset epochs, deterministic simulation-time scheduling,
bounded queues and an event journal with backpressure. It is independently tested without ROS.
It has not yet been wired into the campaign package build/drivers.
